# Contributing

Bug reports should include:

- Linux distribution, PipeWire, WirePlumber, and BlueZ versions
- Bluetooth adapter model
- Earbud model and firmware version
- The SSC profile shown by `pactl list cards`
- Relevant PipeWire or WirePlumber journal messages

Please remove Bluetooth addresses, usernames, and other personal information
from logs before posting them publicly. Changes to the PipeWire patch should
state which upstream PipeWire tag they target.
